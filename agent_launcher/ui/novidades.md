# Agent Launcher 1.3.19

- **Codex e Copilot mais leves:** o launcher abre o Codex e o Copilot CLI direto pelo executável nativo do pacote npm, sem o `node` do carregador. Cada sessão usa uns 65 MB a menos de memória e nenhum processo sobra ao fechar a aba. Sem o pacote da plataforma, o carregador de Node continua como antes.
- **Linha de comando, cinco funções novas (sem mudar o que já existia):** `launcher launch` e `launcher conversations` sem `--project` usam o projeto cadastrado da pasta atual; `launcher connections test` sem o nome testa todas as conexões, uma a uma, e diz o resultado de cada; `launcher usage --months N` lista o total de cada um dos N últimos meses; `launcher conversations --search TEXTO` filtra por título, CLI ou data; `launcher completion powershell` imprime o script que faz o Tab completar comandos, opções, CLIs, projetos e conexões no PowerShell.
- **Iniciar e copiar:** o painel Endpoint local ganhou o botão **Iniciar e copiar** (menu PowerShell ou cmd): sobe o endpoint parado e copia a configuração; com o endpoint rodando, só copia. Os botões de copiar desligados passam a dizer "Inicie o endpoint para copiar".
- **Conexões:** a linha de status fica no rodapé fixo da janela, e a confirmação de uma cópia aparece sem precisar rolar.
- **Cofre de chaves:** o arquivo do cofre é gravado como o blob DPAPI cru, o mesmo formato do native-java; o texto antigo com `dpapi:v1:` continua sendo lido e é migrado na primeira gravação.
