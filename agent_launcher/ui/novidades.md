# Agent Launcher 1.3.21

- **Aider como agente local opcional (acrescenta; nada muda para quem não usa):** o Aider (aider-chat 0.86.2, fixado) aparece como mais um agente, instalado em um ambiente próprio (uv, Python 3.12). Abre em conexão Ollama pela rota nativa do Ollama (`/api/chat`, janela `num_ctx` de 16384), retoma a última conversa da pasta e aceita modelo sem ferramentas. O endpoint local passa também `/v1/embeddings` pela conexão.
- **Ollama, o que o host informa (acrescenta):** o catálogo da conexão Ollama lê o `/api/show` de cada modelo e mostra ferramentas, imagem, embedding e a janela máxima. A janela máxima não é a carregada: o Ollama carrega menos por padrão (`OLLAMA_CONTEXT_LENGTH`), e a janela diz isso. Se o `/api/show` não responder para algum modelo, o status do catálogo diz quais e o que fazer (atualizar com `r`); as consultas dividem um tempo único de 20 s.
- **Claude Code na conexão Ollama (acrescenta):** a conexão Ollama passa a oferecer o Claude Code, além do Aider e do Copilot CLI, com modelo que use ferramentas (provado com qwen3:4b). O Codex continua fora: a prova com o mesmo modelo respondeu sem criar o arquivo.
- **Achar o Ollama, com mais cuidado com o endereço:** a janela e `launcher connections detect` recusam endereço com usuário e senha, `@`, `?`, `#` ou `;` sem repetir o que foi digitado, e a dica de cadastro só cita nome e endereço que um shell lê sem surpresa. O texto da janela cita o Aider, o Copilot CLI e o Claude Code.
- **Sessões do Aider e do Copilot CLI pelo endpoint local (opt-in por conexão, desligado por padrão):** com **Sessões pelo endpoint** ligado na conexão, essas duas ferramentas abrem apontando para o endpoint local, com a chave de mentira do launcher no lugar da real (a real nunca vai para linha de comando nem para o ambiente), e a reserva atende cota esgotada. O Aider em conexão Ollama continua direto ao host. Sem a opção nada muda. O uso do Copilot CLI por esse caminho aparece também em "Endpoint local" (conta em dobro): é o item B100 do backlog.
- **Catálogo:** o adaptador de cada ferramenta decide se o modelo serve a ela; o piso de que embedding, imagem e áudio nunca servem a um agente de texto continua valendo para todos.
